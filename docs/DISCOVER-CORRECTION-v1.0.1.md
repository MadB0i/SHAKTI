# 2026 Durga Puja calendar correction

Researched 16 October 2026, India Standard Time. Supersedes the vehicle presentation in v1.0.0's cultural companion; the original source record is retained as history.

## What the patch says

The prominently displayed universal-looking “Charanayudha · Rooster” departure was misleading beside a Bengali Wednesday Dashami sequence. The replacement is **“Nouka · Boat” explicitly attributed to the Bengali panjika comparison reported by Anandabazar**, with both arrival traditions displayed. Horse departure is reported elsewhere but remains unverified for a universal Bengal/Assam label. No source has been silently altered to match the user's proposed answer.

## Weekday rule used in the Bengali comparison

Arrival uses Saptami; departure uses Dashami. Anandabazar reports the same mapping for both:

| Weekday | Vehicle |
| --- | --- |
| Sunday / Monday | Gaja · Elephant |
| Tuesday / Saturday | Ghotak · Horse |
| Wednesday | Nouka · Boat |
| Thursday / Friday | Dola · Palanquin |

Editorial inference: using the Tuesday start of a Dashami tithi to declare Horse would conflate tithi onset with the Wednesday observance selected by the cited Bengali panjikas. Likewise, combining Drik's Tuesday Visarjan omen label with Wednesday Bengal immersion conflates conventions. Do not infer either mapping for every Assamese community.

## Source reliability and unresolved evidence

- The regional vehicle correction is an attributed synthesis, not a claimed inspection of printed panjika pages.
- Direct 2026 publisher scans or a named local temple's panjika/ritual statement would strengthen a community-specific determination. Their absence does not justify publishing Horse as settled fact.
- Old 2025 stories and unrelated holiday lists were excluded as evidence of 2026 vehicles. Government holidays can corroborate a civil holiday date but cannot determine ritual vehicles.
- Attempts to retrieve location-specific Guwahati Drik/Assamese pages were unsuccessful. No result from an unverified location parameter is used as an Assam determination.
- Belief and omen language is identified as devotional tradition, not a scientific prediction.
