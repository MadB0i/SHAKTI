# Locally served typefaces

- **Cinzel** variable weight font, Natanael Gama / NDISCOVER. Official source: https://github.com/google/fonts/tree/main/ofl/cinzel . Downloaded 2026-10-15, unchanged. See `Cinzel-OFL.txt` for the supplied copyright and SIL Open Font License 1.1.
- **Noto Serif Bengali** variable width/weight font, The Noto Project Authors. Official source: https://github.com/google/fonts/tree/main/ofl/notoserifbengali . Downloaded 2026-10-15, unchanged. See `NotoSerifBengali-OFL.txt` for the supplied copyright and SIL Open Font License 1.1.

Both are bundled locally with their complete licenses. Bengali text is rendered as a complete Unicode string by the browser text shaper; no manual letter splitting or artificial tracking is applied to Bengali.
